# Extended 模式模板

适用：包含多个子系统、复杂状态、跨端契约或多条独立链路的模块。

在 Standard 基础上按实际主题增加章节，常见扩展章节：

```
docs/Framework/<Module>/
├── README.md
├── 01-模块全景.md
├── 02-核心子系统A.md
├── 03-核心子系统B.md
├── 04-运行时链路.md
├── 05-跨模块契约.md
├── 06-关键设计点.md
└── 07-风险与维护.md
```

## 扩展章节的命名规则

- 保持两位数编号（01、02 …）
- 编号只反映推荐阅读顺序，不反映版本
- 新增章节按序追加，不要重新编号已有文件
- 章节数量由内容决定，不应要求达到固定数量

## 可选扩展主题

| 主题 | 适用条件 |
|------|----------|
| 数据模型 | 有自定义数据结构或 Schema |
| 网络同步 | 涉及远程数据同步 |
| 生命周期 | 有复杂状态机或生命周期回调 |
| 缓存 | 有独立缓存策略或存储 |
| 跨端契约 | 多平台共享逻辑或协议 |
| 编辑器工具 | 有自定义编辑器扩展 |
| 配置体系 | 有多层配置覆盖关系 |
| 性能模型 | 有性能敏感路径 |
| 闭环 | 与其他模块形成数据闭环 |
| 故障模式 | 有多条已验证失败路径 |
