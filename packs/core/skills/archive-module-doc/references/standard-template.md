# Standard 模式模板

适用：包含多个核心组件或两到三条稳定链路的模块。

## README.md

```markdown
# <Module> 文档集

`<Module>` 是 <一句话定位>。

模块位置：`<源码目录>`

## 文档状态

- 覆盖范围：<已覆盖主题>
- 最近验证提交：`<commit>`
- 未覆盖：<未覆盖主题>

## 章节索引

| 章节 | 主题 | 适用场景 |
|------|------|----------|
| [01 模块全景](./01-模块全景.md) | 职责、依赖、边界 | 首次了解 |
| [02 核心组件与职责](./02-核心组件与职责.md) | 组件关系 | 修改组件 |
| [03 关键功能链路](./03-关键功能链路.md) | 主链路 | 排查问题 |
| [04 风险与维护](./04-风险与维护.md) | 风险和检查项 | 修改前评估 |

## 推荐阅读路径

- 初次了解：01 → 02
- 排查问题：01 → 03 → 04

## 关联模块

- `<ModuleA>`
- `<ModuleB>`
```
