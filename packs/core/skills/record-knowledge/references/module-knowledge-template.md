# 模块级文档模板

模块文档不应强制填满所有章节。只填写本次已确认的部分。

```markdown
# <模块名称>

## 职责

<一句话描述模块做什么>

## 入口

- `<入口函数或类>`
- `<另一入口>`

## 关键链路

```
<组件A> → <组件B> → <组件C>
```

## 关键状态

- <状态1> 由 <组件> 管理。

## 生命周期边界

- <边界条件>

## 已验证失败模式

### <失败模式标题>

触发条件：

- <条件1>
- <条件2>

结果：

- <后果>

## 实现锚点

- `<源文件路径>`
```

## 关键原则

- 没确认某个章节，就不写该章节。
- 只确认一条链路，就只补链路。
- 不要求第一次调用就把整个模板填满。
- 文档可以逐步成长。
